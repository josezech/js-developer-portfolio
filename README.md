# Portfólio Dinâmico - Desafio DIO

Página de portfólio em HTML, CSS e JavaScript que carrega todos os dados de um arquivo JSON (`data/profile.json`).

## Como funciona
O `main.js` faz `fetch` do JSON e monta os blocos de contato, skills, projetos e experiência. Para atualizar o portfólio, basta editar o JSON.

## Demonstração
https://josezech.github.io/js-developer-portfolio/

## Tecnologias
HTML5, CSS3, JavaScript (fetch, async/await), JSON, Git/GitHub e GitHub Pages.
